Graph-Based Investment Portfolio Recommendation System Using Neo4j and Flask

This project presents a graph-driven investment recommendation system that identifies investor communities and recommends potential assets based on graph algorithms such as PageRank, Jaccard Similarity, and Louvain Community Detection.
Features
- Investor–Asset graph visualization using Neo4j
- PageRank-based investor influence analysis
- Jaccard similarity for investor similarity scoring
- Louvain clustering for community detection
- RESTful API backend (Flask)
- Interactive frontend dashboard for visualization and recommendations

Tech Stack
Backend: Flask, Neo4j, Flask-CORS  
Frontend: HTML, CSS, JavaScript  
Database: Neo4j (Community Edition)

Data
- Investor Data:Synthetic (generated programmatically)
- Asset Data: Fetched from Yahoo Finance API
